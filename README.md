# 第五届"多主体系统中的逻辑"研讨会报告征集通知

2026年10月31日至11月1日，第五届"多主体系统中的逻辑"研讨会将在西安交通大学数学与统计院（兴庆校区）举行。本研讨会主要关注多主体系统的三个方面：主体的能力、主体的知识、系统的规范，让研究者进行充分的交流，大家帮助大家的研究。
请有意参会的学者于 2026年10月18日前将报告题目和摘要发送到：
lmas2026@163.com。
经会议委员会审核通过后，将向您发送最终的参会邀请。本会议不收注册费，差旅费和住宿费自理。

会场位于交通大学兴庆楼（兴庆校区北门附近）2-1会议室，地铁6号线交通大学兴庆宫站下车即是。

推荐住宿：德泉酒店（西安交通大学兴庆宫地铁站店）、桔子酒店(西安交通大学兴庆宫地铁站店)（到会场十几分钟步行距离）。

有任何问题，欢迎您联系张奎泽（kuize.zhang@xjtu.edu.cn）。
